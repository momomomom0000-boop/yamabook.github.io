WEB GAME / THREE.JS / LOW-POLY / CASE STUDY

授業中の空腹とローポリの衝動から生まれた育成シミュレーション「CHIKUWA WORLD」

  • 担当: 企画・世界観設計・AI対話・フロントエンド実装（100%個人制作）
  • 制作期間: 約3時間（超短期スプリント）
  • ツール: Three.js / AIツール / VS Code / HTML5 / CSS3 / JavaScript
成果物Webサイト（ゲーム）を見る ↗

01. 概要と誕生のきっかけ / Concept & Story

「CHIKUWA WORLD」は、ローポリゴン3D表現と独自の哲学・育成要素を融合させたブラウザ向け育成シミュレーションゲームです。
ある日の授業中、隣の席の佐藤さんとお酒の話をしているうちに「おでんが食べたいな」と思い立ったことがすべての始まりでした。そこからなぜか「ちくわの穴はちくわの一部なのか？」といった疑問や製造過程、歴史についてAIと対話しながら深く思いを巡らせることに。同時期に目にした『ゼルダの伝説 時のオカリナ』のリメイクニュースから「ローポリゴンの質感が失われるのはもったいない」という思いも重なり、「ローポリゴン」と「ちくわへの探求心」を合体させて形にした作品です。

プロジェクトのこだわり & 目指した体験

  • シュールで知的な世界観： 単なるクリックゲームに留まらず、ちくわの哲学や原材料、歴史、地方の名産品などを網羅したレベルアップ解放型の図鑑システムを実装。
  • 頑固なおやじの存在感： 熟練のちくわ職人「源さん」を登場させ、習熟度が上がるにつれて口数が多くなり、熱く語りかけてくるテキスト演出で工房のライブ感を演出。

02. 制作プロセスと技術的こだわり / Process & Technology

📐 Three.jsによるローポリ3D表現

Three.jsを用いて、カクカクとした独特の美しさを持つローポリゴンちくわを動的に生成。マウスやタッチで360度自由に回転させることができ、所持するアイテムや育成段階によって見た目や質感が変化する仕組みを構築しました。

📖 約3時間の超短期スプリント開発

「クリックしてすり身の微塵や経験値を貯める」というストレスコア制作時の手軽さを活かしつつ、AIとの対話から得たアイデアをわずか約3時間で一気にコーディング。レベルアップに応じた図鑑解放などのやり込み要素を凝縮しました。

03. 実装とキャラクター演出の工夫 / Implementation & UX

プレイヤーが思わずクスリと笑い、何度も工房に足を運びたくなるようなインタラクションを盛り込みました。

  • 頑固職人・源さんの育成フレーバー：
    最初はぶっきらぼうな一言だったおやじが、習熟度が上がるにつれて職人としてのこだわりや熱量を爆発させ、テキストボックスからあふれんばかりに喋り出す変化を実装。
  • レトロ＆チルなトーン＆マナー：
    CRT風のスキャンラインやダークトーンの色彩設計を取り入れ、深夜におでんの湯気を眺めているような落ち着いた雰囲気を演出しました。

04. 成果と今後の展望 / Achievements & Next Step

💡 制作を通じた大きな気づき

前作のクリックゲーム（ストレスコア）のシンプルさを活かしつつ、ビジュアル表現（Three.js）、トロフィー・図鑑要素、そしてキャラクター性を掛け合わせることで、コンテンツとしての深みが劇的に変わることを実感しました。ブラウザゲーム開発の奥深さを知ると同時に、「自分のふとした思いつきやシュールな疑問をAIとの対話を交えて約3時間で形にする楽しさ」を強く学ぶことができました。この経験を糧に、今後はさらに一段階レベルを上げたインタラクティブな表現やゲーム制作に挑戦していきたいと考えています。
