広告的虚構を排し、妥協なき臨床哲学を貫く──異色のクリニックサイト「北青山・轟内科医院」

  • 担当: ブランディング・UI/UX設計・コピーライティング・フロントエンド実装（個人制作）
  • 制作期間: 約1週間
  • ツール: HTML5 / CSS3 / JavaScript / VS Code / Figma

01. 概要とプロジェクトの背景 / Concept & Background

「北青山・轟内科医院」は、現代の医療・健康情報サイトにあふれる「広告代理店的的美辞麗句や耳障りの良い虚構」に対する強烈なアンチテーゼとして設計された架空のクリニック向けWebサイトです。
昨今のクリニックサイトは、どこも同じような笑顔のストックフォトや「痛くない・すぐ治る」といった無責任なキャッチコピーで溢れています。それに対するカウンターとして、東京・北青山という最先端の街にありながら、あえて90年代初期のパーソナルWeb風の質感（クラシックグレー、ベベル枠、アクセスカウンター、流れる警告テロップ）を採用。
院長「轟 健太郎」の妥協なき臨床哲学を剥き出しにすることで、他のどの医療サイトにも真似できない圧倒的な信頼感と独自性（USP）を確立しました。

デザイン・ブランディングの核

  • 広告的虚構への完全なる拒絶： 綺麗ごとのマーケティング用語を一切排除し、生理学・臨床医学に裏打ちされた硬派なトーン＆マナーを貫く。
  • レトロWebによる記憶定着： あえて90sのビジュアル文法を用いることで、情報過多な現代のWeb空間において強烈な差別化と記憶フックを生み出す。

02. 世界観設計とUI/UXの工夫 / Worldview & UI/UX

🖥️ 90sカルチャーとモダンWebの融合

アクセスカウンターやmarquee風の警告テロップといったノスタルジックな表現を取り入れつつ、現代のWeb標準であるレスポンシブ対応、セマンティックなHTML構造、およびアクセシビリティ（aria属性）を徹底的に両立させました。

🖼️ モノクロ線画が生む絶妙な「抜け感」

硬派で重厚な医学論の合間に、学校のお便りを彷彿とさせるモノクロの挿絵イラストを絶妙なバランスで配置。シュールなユーモアを生み出すことで、読者が硬い文章に萎縮せず、最後まで惹き込まれる心地よいリズムを生み出しています。

03. 広告を否定する全20問のQ&Aコーナー / Copywriting & Q&A

本サイトの最大の看板となる「患者からの挑戦状（ガチお悩み・Q&A）」では、世にはびこる商業的な健康法や誤った自己判断をQ1からQ20まで容赦なく一刀両断・添削しています。

  • 広告的コピーの論理的粉砕：
    「朝バナナダイエット」や「サプリの過剰摂取」、「ネット検索による自己診断」など、広告やSNSで拡散される安易な健康神話を、代謝や生理学の原則に基づいて徹底的に論破。
  • ツンデレ的誠実さの演出：
    一見すると厳しい言葉の奥底に滲む、「患者の大切な身体を、根拠のない商売や流行に預けてほしくない」という臨床医としての深い矜持と誠実さが、高い没入感と信頼感を醸成しています。

04. 成果と今後の展望 / Achievements & Next Step

💡 プロジェクトを通じた気づき

ありふれたテンプレートデザインとは対極にある「強烈なペルソナと世界観」をWebサイト全体に貫くことで、単なる情報提示を超えた記憶に残るブランド体験を構築できることを実証しました。ヴィジュアルのレトロさと、中身の圧倒的な文章量・医学的ロジックのギャップがもたらすシナジーは、今後のWebデザイン・ブランディング制作における大きな武器になると確信しています。
