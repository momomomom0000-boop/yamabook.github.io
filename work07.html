ペットショップ・テラ Webサイト制作 & ホラーゲーム化アレンジ

  • 担当: デザイン調整・カラーパーツ加工・高速コーディング・ホラーゲーム企画実装（100%個人制作）
  • 制作時間: 約2時間（高速コーディング + ホラー演出組み込み）
  • ツール: HTML5 / CSS3 / JavaScript (Vanilla JS, Web Audio API, Canvas API) / Photoshop

01. 概要とコンセプト / Concept & Overview

課題制作の高速コーディングで生まれた余剰時間を活用し、平和な「ペットショップ・テラ」のWebサイトを侵食する**体験型ブラウザホラーゲーム（裏Webサイト）**を企画・制作しました。ネット都市伝説、バックルームズ（The Backrooms）、SCP財団の不穏な世界観をインスピレーションに、日常のWebサイトが異形や異常性へ変貌していく恐怖体験を構築しています。

ホラーゲームの主要コンセプト

  • 「日常」から「怪異」への歪み： 一見すると親しみやすいペットショップサイトだが、隠された操作や特定の「異変」によって深層の裏サイトへ遷移。
  • ネット都市伝説・SCPのオマージュ： 擬態種「オルタネイト」や収容違反、暗号化された施設ログなど、プレイヤーの考察欲を刺激する世界観設定。
  • インタラクティブな探索要素： 全10種の実績バッジ解除、隠しテキストドラッグ、CLI（黒いコマンドライン）での暗号解読や監視カメラ操作。

02. 視覚・音響による不気味さの演出 / Visual & Sound System

👁️ CRT走査線 & 画面侵食エフェクト

ホラーモード発動時、背景は黒（#050505）と深紅（#8B0000）へ激変。CSSアニメーションによるCRTモニター風走査線やグリッチ振動で、バックルームズの不気味な閉塞感を演出しました。

🔊 Web Audio API による動的音響生成

外部音声ファイルの読み込みに頼らず、Web Audio APIで不穏な低周波ドローン音や不協和音、心拍振動音をプログラマブルにリアルタイム生成。没入感の高い音響演出を実現しました。

📹 Canvas API リアルタイムノイズ監視カメラ

CLIターミナルからアクセスできるCCTV監視カメラ映像をJavaScript Canvas APIで描画。動的な砂嵐ノイズと異常な被写体の映り込みをプログラム制御しています。

03. 実装ギミックと探索メカニクス / Game Mechanics

  • 裏管理ターミナル（CLI）と9桁暗号解読：
    ロゴの連打やフッター隠しテキストから起動するターミナル。HELP、CCTV、UNLOCK 198802142 などのコマンド入力でストーリーが進行する謎解きパズルを実装。
  • 隠しテキストドラッグ & 順番指定クリック：
    カーソルで範囲選択（ドラッグ）した時のみ浮き出る不吉なログメッセージや、特定の順番でスタッフカードをタップすることで発動するジャンプスケア（心拍揺れ演出）。
  • 全10種の実績解除バッジシステム：
    プレイヤーがサイト内の「異常」を発見・操作するたびに実績バッジがアンロックされるコンプリート要素（LocalStorageでの状態保存）を構築。

04. 制作プロセス（開発タイムライン） / Development Timeline

PHASE 01

表Webサイトの高速コーディング & フラグ設計

課題の通常Webサイト（ペットショップ・テラ）を正確かつ高速に構築しつつ、裏モードへの切替用CSS変数やJavaScriptのイベントリスナー（隠しフラグ）を初期設計。

PHASE 02

ホラー演出・異変ギミック・CLIターミナル実装

バックルームズ/SCPモチーフのフレーバーテキスト作成、ロゴ連打・テキストドラッグ等のトリガー設定、コマンドライン（CLI）画面および9桁暗号解読パズルを実装。

PHASE 03

Web Audio / Canvas 音響ノイズ構築 & 実績システム

Web Audio APIによるホラー効果音・低周波音の動的生成と、Canvas APIによる監視カメラノイズを描画。全10種の実績バッジアンロック判定と演出の調整を完了。

05. 成果・技術的知見 / Achievements

💡 フロントエンドにおけるインタラクティブ表現の獲得

同一HTML上で状態変数（CSS/JS）をコントロールし、「日常サイト」から「ホラーゲーム」へとシームレスに変貌させるDOM・状態管理技術を体得しました。また、外部ライブラリなしでWeb Audio APIやCanvas APIを駆使した直感的な恐怖演出（音響・映像ノイズ）を実装できたことは、表現の幅を大きく広げる成果となりました。
